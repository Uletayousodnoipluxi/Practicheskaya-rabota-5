Функционал модулей
2.1. Модуль аутентификации (auth-module)
•	Регистрация пользователя: Создание нового аккаунта с валидацией данных.
•	Авторизация (login): Аутентификация пользователя по логину и паролю.
•	Выход (logout): Завершение сеанса пользователя.
2.2. Модуль управления задачами (tasks-module)
•	CRUD-операции:
o	Create — создание задачи;
o	Read — просмотр списка задач;
o	Update — редактирование задачи;
o	Delete — удаление задачи.
•	Фильтрация и поиск: Поиск задач по названию, статусу, дате и другим параметрам.
•	Изменение статуса: Возможность перевода задачи между статусами (например, "к выполнению", "в процессе", "выполнено").
2.3. Модуль отчётности (reports-module)
•	Генерация отчётов: Формирование отчётов по задачам за определённый период.
•	Статистика выполнения: Визуализация данных о продуктивности (количество выполненных задач, время выполнения и т.д.).
•	Экспорт данных: Сохранение отчётов в форматах CSV или PDF.
3. Взаимодействие между модулями
•	Модуль аутентификации предоставляет сервис проверки авторизации для других модулей. Например, перед выполнением операций с задачами система проверяет валидность сессии пользователя.
•	Модуль управления задачами передаёт данные о задачах в модуль отчётности для генерации статистики.
•	Основное приложение (main-app) выступает в роли интеграционного слоя, обеспечивающего взаимодействие модулей через API или прямые вызовы методов.
Пример взаимодействия:
1.	Пользователь входит в систему через auth-module.
2.	После успешной авторизации он получает доступ к tasks-module.
3.	При запросе отчёта tasks-module передаёт данные в reports-module, который возвращает сгенерированный отчёт.
